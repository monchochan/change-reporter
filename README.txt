変化発見レポーター PWA（公開用）
==================================

公開用ファイル:
- index.html
- manifest.webmanifest
- sw.js

GitHub Pages等でHTTPS公開すると、iPhone Safariから利用できます。
GitHub Pagesでは、この3ファイルをリポジトリの公開フォルダ直下に置き、Settings > Pages で公開します。
公開URLをiPhoneのSafariで開き、共有 > ホーム画面に追加 でアプリ風に起動できます。

プライバシー:
- 公開用ソースコードには個人の測定値を含めていません。
- 測定値は利用端末のブラウザ localStorage に保存し、アプリのサーバーへ送信しません。
- ただし、公開ページ自体は誰でもアクセスできます。GitHub Pagesの公開サイトではアクセス元IP等がセキュリティ目的で記録されます。
- localStorageは暗号化保管ではありません。端末のパスコードを設定し、共有端末では利用しないでください。
- SafariのWebサイトデータ削除・端末故障等で記録が消える可能性があります。設定画面からJSONバックアップを定期的に保存してください。

初期データの登録:
- 公開用ソースには個人データを埋め込んでいません。
- 初期データが必要な場合は、別途提供する非公開JSONバックアップをアプリの「設定・バックアップ」から読み込んでください。
- JSONバックアップはGitHub等の公開リポジトリへアップロードしないでください。

注意:
同じiPhone・同じSafariの保存領域で利用してください。ホーム画面追加後も、Safariで開いた同じサイトのデータ領域を使用します。

今回のセキュリティ確認・修正:
- 外部JavaScript/CDN/アクセス解析は使用していません。
- 履歴表示時に入力値をHTMLとして解釈しないようエスケープ処理を追加しました。
- JSON復元時にファイルサイズ・件数・日付・各測定値・メモの形式を検証します。
- Service Workerは同一サイトのアプリ本体ファイルだけをキャッシュし、外部サイトへの通信を横取りしません。
- これは基本的な対策であり、第三者による侵入テストや専門的なセキュリティ監査を完了したものではありません。
